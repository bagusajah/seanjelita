# Sean & Jelita — Wedding Invitation Website

A static, single-page **wedding invitation website** for the wedding of **Sean & Jelita** (20 December 2018). Built with the ["Wonderful Wedding"](https://github.com/templatedash/wonderful-wedding) Bootstrap 4 template.

> ℹ️ **This repository is archived.** It is kept for historical reference and is no longer maintained.

## ✨ Features

- **Single-page** layout with smooth-scroll navigation
- Sections: Home announcement, Groom & Bride, Events, People (wedding party), Gallery, and RSVP
- **Responsive** design built on Bootstrap 4
- **Lightbox gallery** (Ekko Lightbox) for photos
- **Scroll animations** via AOS (Animate On Scroll)
- Elegant typography using *Great Vibes* and *Dosis* Google Fonts
- Social links for the couple

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 |
| Styling | Bootstrap 4, Font Awesome, custom `main.css` |
| Scripts | jQuery, Bootstrap JS, AOS, Ekko Lightbox |
| Fonts | Great Vibes, Dosis (Google Fonts) |

## 🚀 Usage

This is a static site — no build step or server required.

1. **Open locally:** just open `index.html` in a browser.
2. **Customize:** edit text directly in `index.html`; edit styles in `css/main.css`; replace images in `images/` (keep the same filenames, or update the references in `index.html`).
3. **Deploy:** upload all files to any static web host (GitHub Pages, Netlify, S3, or a traditional FTP host). Keep `index.html` at the root.

See `README.txt` for the original template editing instructions.
